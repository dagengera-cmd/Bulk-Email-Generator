# Outlook Email Automator (Windows Desktop Edition)

A standalone Windows desktop email generator with **persistent local memory**, **merged-cell & multi-block Excel parsing**, and **1-click Microsoft Outlook draft generation**.

## How to Get Your `.exe` Automatically on GitHub
1. Create a new repository on [GitHub](https://github.com/new).
2. Click **"uploading an existing file"** and drag **all files and folders** from this ZIP (make sure the `.github` folder is included!) into your repository, then click **Commit changes**.
3. Click the **Actions** tab at the top of your GitHub repository.
4. Wait ~1–2 minutes for the **"Build Windows EXE"** workflow to finish with a green checkmark.
5. Click on the completed workflow run and download **`OutlookEmailAutomator-Windows`** under **Artifacts** to get `OutlookEmailAutomator.exe`!
